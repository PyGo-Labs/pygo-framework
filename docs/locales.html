locales

Package locales provides i18n support for Python handlers. Loads JSON dictionaries from core/runtime/locales/{en,es}.json and exposes t(key) function.

Functions

GetAll

GetAll returns all loaded locales (for debugging/inspection).

Load

Load loads locale dictionaries from the locales directory. Called once at startup by the Python runtime (pyclient serve)...

T

T translates a key for the given locale. Falls back to "en" then key itself.
