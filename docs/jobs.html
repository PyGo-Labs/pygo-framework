jobs

jobs

Package jobs provides an in-memory background job queue. It uses a buffered channel + a worker goroutine — no external deps (no Redis, no frameworks). The actual Python execution is delegated via an Executor callback provided at Init time (avoids import cycle jobs→runtime).

Types

Executor

Executor is the function that runs a job (e.g., calls Python via runtime.CallPython).

Job

Job tracks a single background execution.

JobNotFoundError

JobNotFoundError is returned when a job ID doesn't exist.

Queue

Queue is an in-memory job queue with a single worker goroutine.

Status

Status is the lifecycle state of a job.

Functions

EnqueueJob

EnqueueJob is the package-level entry gen_go calls. It returns a map so the router can JSON-encode it directly as a 202 ...

GetJob

GetJob returns a job's status by ID. gen_go uses this for the /jobs/:id route.

Init

Init starts the default queue with the given executor. Safe to call once.

Shutdown

Shutdown stops the worker goroutine (graceful).
