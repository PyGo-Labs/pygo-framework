runtime

Package runtime supervises the Python subprocess and exposes CallPython, the bridge the transpiler-generated gen_go.go uses to delegate handlers to Python. Lifecycle: 1. Supervisor.Start opens the UDS listener (Go is the server). 2. It launches `python3 <module>` with PYGO_SOCKET set to the socket path. 3. It waits (Accept) for the Python client to dial in. 4. CallPython sends a {handler, args} frame and blocks for the response. The package keeps a process-wide default Supervisor so generated code can call the package-level runtime.CallPython without threading a handle everywhere. Package runtime — test helpers for PyGo dual-language integration tests. Provides repoRoot() and contains() used by v-series integration tests.
