dev

Package dev implements the PyGo development server with hot-reload. pygo dev starts the Go web layer and Python domain server, watches for file changes (*.go, *.py, *.html, *.toml), and auto-restarts on modify. No transpiler, no DSL — native dual-language hot-reload.

Types

Server

Server coordinates the Go binary launch with live file-watching for hot-reload.

Start

Start launches the Go binary and watches files for changes.
