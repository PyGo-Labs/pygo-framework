http

Package http provides routing for PyGo framework. Extends Go's net/http with dynamic routes, groups, and middleware. Package http provides HTTP server and routing built on Go's net/http.

Types

MiddlewareFunc

MiddlewareFunc is a middleware function.

Route

Route represents a registered route.

RouteGroup

RouteGroup is a group of routes with a common prefix.

Router

Router is an enhanced router with dynamic parameters.

Server

Server is the PyGo HTTP server.
