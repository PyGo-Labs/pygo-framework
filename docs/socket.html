socket

Package socket implements the Unix Domain Socket transport between the Go server and the Python runtime. Payloads are MessagePack-encoded frames of the shape {handler: string, args: map}. Each frame is length-prefixed (4-byte big-endian uint32) so Send/Recv can operate on a streaming connection.
